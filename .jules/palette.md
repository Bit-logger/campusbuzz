## 2025-02-28 - Custom Interactive Component Accessibility
**Learning:** When building custom interactive components like `SquishyButton` that wrap `TouchableWithoutFeedback` or similar primitive touchable elements in React Native, accessibility properties are not forwarded automatically. Screen readers need `accessibilityLabel`, `accessibilityRole`, and `accessibilityState` explicitly passed to the root interactive element to function properly. Fallbacks for `accessibilityLabel` using component string `label` props should be typed checked to avoid passing React nodes.
**Action:** Always manually forward accessibility props (especially `accessibilityLabel`, `accessibilityRole`, and `accessibilityState`) to the root touchable primitive when creating or modifying custom interactive components.
