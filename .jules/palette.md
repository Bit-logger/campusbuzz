## 2024-10-13 - Forwarding Accessibility Props in Custom React Native Components
**Learning:** Custom wrapper components (like `SquishyButton` wrapping `TouchableWithoutFeedback`) don't automatically pass down accessibility properties. This means if you use the custom component anywhere, screen readers may completely miss its purpose or state unless these props are explicitly forwarded to the root interactive element. Also, passing `undefined` to `accessibilityLabel` allows React Native to fall back gracefully if no label string is available.
**Action:** When creating or modifying custom interactive components (like buttons or toggles), always add `accessibilityLabel`, `accessibilityRole`, and `accessibilityState` to the component's API and explicitly forward them to the underlying native touchable element.
