## 2026-10-10 - Custom Interactive Component Accessibility
**Learning:** React Native custom interactive components (like SquishyButton using `TouchableWithoutFeedback`) drop implicit accessibility roles/labels if not manually forwarded from the component props to the underlying interactive element. Furthermore, fallback logic (`accessibilityLabel || label`) fails for screen readers if `label` is not a string but instead passed implicitly via `children`.
**Action:** When creating or modifying custom touchable wrappers, always explicitly accept and forward `accessibilityLabel`, `accessibilityRole`, and `accessibilityState` to the root interactive component to ensure robust screen reader support. Add descriptive `accessibilityLabel` attributes to any icon-only touchable elements to bridge usability gaps.
