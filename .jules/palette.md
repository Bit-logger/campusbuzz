## 2024-05-24 - Explicitly forwarding accessibility props to custom interactive components
**Learning:** When building custom interactive components in React Native (e.g., SquishyButton which wraps TouchableWithoutFeedback), accessibility props like `accessibilityLabel`, `accessibilityRole`, etc., are not automatically passed down to the underlying generic components. Also, passing React node to `accessibilityLabel` using a fallback prop (e.g. `accessibilityLabel || label`) will cause errors.
**Action:** Always explicitly accept and forward accessibility props to the root interactive element (e.g., `TouchableWithoutFeedback`, `Pressable`, `TouchableOpacity`). Ensure that the fallback value for `accessibilityLabel` is explicitly checked to be a string. Furthermore, always provide an `accessibilityLabel` to icon-only buttons so screen readers can interpret them properly.
