## 2023-10-20 - Custom Interactive Elements in React Native
**Learning:** When building custom interactive components (like `SquishyButton` built with `TouchableWithoutFeedback` and `Animated.View`) instead of using default native elements, standard accessibility traits (like screen reader labes or button roles) are not automatically applied to complex child elements, causing buttons to be inaccessible or vaguely announced.
**Action:** Always explicitly accept and forward `accessibilityLabel`, `accessibilityRole`, and `accessibilityState` props from custom wrapper components down to the root interactive element (e.g., `TouchableWithoutFeedback`). Use a safe fallback for strings (e.g. `accessibilityLabel || (typeof label === 'string' ? label : undefined)`) to prevent crashing when React nodes are mistakenly passed as text labels.
