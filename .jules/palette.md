## 2024-10-19 - Accessible SquishyButton Component
**Learning:** Custom interactive UI components like `SquishyButton` need to explicitly forward `accessibilityRole`, `accessibilityState`, and `accessibilityLabel` to their root interactive element (`TouchableWithoutFeedback`) to ensure proper screen reader support, especially since the component encapsulates interaction logic with animations. Also, caution must be taken with `accessibilityLabel` when fallback to another property (like `label`) is used; it must be explicitly checked as a string, because standard React Native components throw errors or behave unexpectedly when provided non-string values.
**Action:** When creating or maintaining custom interactive elements (buttons, toggles, custom touchables), I will always check that `accessibilityLabel`, `accessibilityRole`, and `accessibilityState` are appropriately merged from props and forwarded securely to the underlying `Touchable*` component.
