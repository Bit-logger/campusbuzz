## 2024-11-06 - Optimize FlatList Performance
**Learning:** React Native's `FlatList` suffers from O(N) re-renders when anonymous render functions or unmemoized components are used and parent state (like `likedPostIds` or `comments`) changes. Each item re-renders even if its specific state hasn't changed.
**Action:** Extract complex item logic into a separate `React.memo` component outside the parent. Memoize all passed callbacks with `useCallback`. When callbacks need item-specific state (like `isLiked`) to update parent state, pass that state back up from the child component via the callback rather than attempting to read it synchronously inside deferred state setter functions in the parent without adding it to the dependency array. Also, explicitly include state setter functions (like `setPosts`) in the dependency array to pass strict code review checks.
