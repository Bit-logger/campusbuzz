## 2024-05-15 - React Native FlatList Re-render Optimization
**Learning:** In React Native, `FlatList` elements can experience severe O(N) re-render performance issues if the `renderItem` function inline constructs components that depend on changing parent state (e.g., `likedPostIds` or `currentUser`). Even minor state changes at the list level will force all items to re-render, leading to lag and blocking the main thread.
**Action:** Extract complex item logic into a separate `React.memo` component and memoize all passed callbacks (`onLike`, `onDelete`, etc.) using `useCallback`. Crucially, to avoid stale closure bugs or adding frequently changing parent state (like `likedPostIds`) to the callback dependency arrays, pass the required state back up from the child component via the callback rather than attempting to read it synchronously inside deferred state setter functions.
