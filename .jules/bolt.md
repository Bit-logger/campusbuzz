## 2023-11-01 - Optimizing FlatList by Memoizing Items and Passing State Up
**Learning:** In React Native `FlatList`, if an item component requires item-specific state (like `isLiked` from a parent `Set` of IDs), updating the parent state causes O(N) re-renders for all items. We can optimize this by extracting the item logic into a separate `React.memo` component and passing the required item-specific state back up from the child component to the parent's memoized callback (e.g. `onLike(item, isLiked)`), avoiding adding the state to the callback's dependency array.
**Action:** Always extract complex list items into `React.memo` components. Use `useCallback` with complete dependency arrays (including setters) for handlers. To avoid constant recreation of callbacks, pass item-specific derived state from the child to the parent handler.
