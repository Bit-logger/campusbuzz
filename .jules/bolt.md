## $(date +%Y-%m-%d) - Memoizing FlatList Items for Performance
**Learning:** In React Native, `FlatList` component will unnecessarily re-render all its items if the parent component's state changes (like appending a new post or interacting with a post like toggling a like) and the rendered items aren't memoized. Wrapping items in `React.memo` isn't enough; callbacks passed to the item component (e.g. `handleLike`, `openComments`) must also be memoized using `useCallback` to prevent breaking the memoization comparison due to newly generated function references on each parent render.
**Action:** When creating a `FlatList` or any long list in React Native, extract the complex item logic into a separate `React.memo` functional component and wrap all functions passed as props in `useCallback` to prevent O(N) re-renders.
