## 2024-05-18 - Animated.Value React Re-Render Pattern\n**Learning:** Passing `new Animated.Value(...)` directly to `useState` causes a new Animated object to be created in memory on every render, which gets immediately garbage collected. This is a common performance pitfall in React Native animations.\n**Action:** Use lazy initializers like `useState(() => new Animated.Value(...))` for complex objects to avoid unnecessary instantiation and garbage collection overhead.
