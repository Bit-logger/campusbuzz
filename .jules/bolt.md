## 2025-01-20 - Memoizing React Native FlatList Items
**Learning:** In React Native, `FlatList` items will all re-render when a parent component's state changes (like a `Set` of liked posts or a current user). This happens because the `renderItem` function and the callbacks it uses are recreated on every render, causing O(N) re-renders which severely degrades performance on long lists.
**Action:** Always extract the item rendering logic into a separate `React.memo` component (e.g. `PostItem`). For callbacks passed to this component (like `onLike`), memoize them using `useCallback` in the parent component and ensure their dependencies do not frequently change. For instance, pass boolean props (like `isLiked`) to the callback rather than having the callback depend on an ever-changing map or array from state.
