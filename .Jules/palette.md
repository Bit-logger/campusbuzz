## 2024-05-24 - Accessibility Props in Custom Animated Components
**Learning:** In React Native, custom interactive components like `SquishyButton` (which wrap `Animated.View` inside `TouchableWithoutFeedback`) often break screen reader functionality if accessibility props aren't explicitly forwarded. `TouchableWithoutFeedback` acts as the root touch target, so it must receive `accessible`, `accessibilityRole`, and `accessibilityState` to properly announce itself to assistive technologies.
**Action:** Always forward `accessibilityLabel`, `accessibilityRole`, `accessibilityState`, and `accessibilityHint` to the outermost interactive element (like `TouchableWithoutFeedback` or `Pressable`) when building custom buttons, especially when they use complex inner animations. Include a sensible default like `accessibilityRole="button"`.
