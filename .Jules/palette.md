## 2024-05-18 - Forwarding A11y Props in Custom Animated Components
**Learning:** Custom interactive components like `SquishyButton` built with `TouchableWithoutFeedback` and `Animated.View` often swallow accessibility properties. If a custom component doesn't explicitly forward `accessibilityLabel`, `accessibilityRole`, and `accessibilityState` down to the underlying React Native interactive primitive (e.g., `TouchableWithoutFeedback`), the entire interactive surface becomes opaque to screen readers, especially when wrapping icon-only or dynamic content.
**Action:** Always ensure custom button components destructure and forward at least `accessibilityLabel`, `accessibilityRole`, and `accessibilityState` to the root interactive element. For reusable components wrapping text/icons, provide a fallback where `accessibilityLabel` defaults to the visible `label` prop.
