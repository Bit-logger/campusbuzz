## 2026-10-03 - Forwarding accessibility props to interactive elements
**Learning:** Custom interactive components (like SquishyButton) using TouchableWithoutFeedback or similar primitives often lack built-in accessibility support if props aren't explicitly passed through. We must ensure accessibility properties like accessibilityLabel, accessibilityRole, accessibilityState, and accessibilityHint are passed to the root interactive element. Furthermore, providing a fallback for accessibilityLabel using a React node (e.g., label prop when it can be anything) causes errors in React Native; ensuring it's a string prevents crashes.
**Action:** When creating or modifying custom interactive components, always extract and forward accessibility props to the root interactive element. Use a string-check fallback for accessibilityLabel.
