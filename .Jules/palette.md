## 2024-10-07 - Forwarding Accessibility Props in Custom Interactive React Native Components
**Learning:** Custom interactive components in React Native like `SquishyButton` that wrap `TouchableWithoutFeedback` don't automatically expose standard accessibility props to the accessibility tree. Furthermore, when creating fallback values for `accessibilityLabel` based on standard text labels (e.g. `label` prop), it's important to type-check that the fallback is actually a string. Passing a React node (which `label` sometimes is) directly to `accessibilityLabel` will cause invalid prop errors on React Native.
**Action:** Always explicitly forward `accessibilityLabel`, `accessibilityRole`, and `accessibilityState` down to the root interactive element. And ALWAYS wrap string fallbacks for A11y labels in `typeof label === 'string' ? label : undefined` to prevent crashes when components accept React nodes as labels.
