## 2024-05-17 - Forwarding Accessibility Props in Custom Interactive Components
**Learning:** Custom interactive components like `SquishyButton` built with `TouchableWithoutFeedback` or `Animated.View` need to explicitly forward accessibility props (`accessibilityLabel`, `accessibilityRole`, `accessibilityState`, `accessibilityHint`) to the root interactive element. Otherwise, screen readers will not correctly identify the component, its state, or its purpose. We also learned that `accessibilityLabel` must be a string, so we must safely fall back to the `label` prop only if it is a string type.
**Action:** Always include and forward `accessibilityLabel`, `accessibilityRole`, `accessibilityState`, and `accessibilityHint` in custom button or interactive components. Merge internal state (like `disabled`) with any incoming `accessibilityState`.
